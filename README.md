# 코레일플러스 UI 재현 + 신규 기능 제안 프로토타입

실제 앱 화면을 계측 기반으로 재현하고, 두 가지 신규 기능의 삽입 지점을 제안하는 프로토타입입니다.

## 제안 내용
| 기능 | 위치 | 근거 |
|---|---|---|
| 미니게임 (레일런) | 홈 → 서비스 그리드 3행 4열 | 기존 11개 + 1 = 4×3 격자를 정확히 채움 |
| 탄소리포트 | 마이페이지 → 계정 관리와 마일리지 사이 | 계정 정보 다음, 리워드 앞 = "내가 만든 결과" |

## 화면
- `index.html` — 홈
- `allmenu.html` — 전체메뉴
- `mypage.html` — 마이페이지
- `game.html` — 레일런 미니게임
- `carbon.html` — 탄소리포트

## 시연 동선
홈 → 전체메뉴 → 마이페이지 → 탄소리포트
홈 스크롤 → 미니게임 → 레일런

## 레일런 모드

PLAY → 클래식 또는 타임어택 선택. 클래식은 거리 내림차순,
타임어택은 서울에서 부산 417km 완주 시간 오름차순으로 랭킹을 표시합니다.
타임어택은 기존 거리·부스터 규칙을 사용하며, 일시정지 시간은 제외하고
탈선한 기록은 등록하지 않습니다. TOP 3와 내 기록 주변 최대 10개를 표시합니다.

타임어택 서버 저장을 활성화하려면 Supabase SQL Editor에서
[`supabase/time-attack.sql`](supabase/time-attack.sql)을 한 번 실행하세요.
이 테이블은 기존 프로토타입과 동일하게 익명 클라이언트의 기록 등록을 허용합니다.

## 강조 효과 끄기
각 HTML의 `<body data-demo="on">` 을 `"off"` 로 변경

## 계측 기준
갤럭시 S25+ / 1080×2340 / density 450 / 배율 2.8125 / 논리 384×832dp
좌표는 `adb uiautomator dump` 실측값, 글꼴 크기는 렌더링 대조로 역산,
색상은 스크린샷 픽셀 추출.
